## About this repo

My running log of competitive programming — Codeforces problems, patterns, and the grind of getting from *Time Limit Exceeded* to *Accepted*. Two tracks running in parallel:

- **Codeforces** — solving upward from 800-rated problems: combinatorics, array manipulation, interval DP, and whatever the next rating band throws at me.
- **NeetCode** — pattern practice and revision, used alongside CF to build intuition faster and recognize problem types on sight.

Everything here is in Python.
